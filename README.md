# Claude Certified Architect – Foundations · Study Tracker

A self-contained study tracker for the **CCA-F** exam: a 3-week plan with
checkable tasks, per-day materials (courses, docs, videos), a progress meter,
and a dark/light theme toggle. Your progress and theme are saved in the browser.

## View it live (GitHub Pages)

1. Put `index.html` in the root of a **public** repo.
2. Repo **Settings → Pages**.
3. Under **Build and deployment**, set **Source → Deploy from a branch**,
   **Branch → `main`**, folder **`/ (root)`**, then **Save**.
4. Wait ~1 minute. Your tracker publishes at:
   `https://<your-username>.github.io/<repo-name>/`

## Run it locally

Just open `index.html` in any browser — no build step, no dependencies.

## Notes

- Single file. The only external request is Google Fonts (loads from their CDN).
- Progress is stored per-URL in your browser, so keep the same repo/URL to keep
  your checkmarks. Opening the same link on another device keeps its own copy.
